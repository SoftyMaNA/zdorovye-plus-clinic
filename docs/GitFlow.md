# GitFlow

Локальный учебный пример отрабатывает ветки main, develop, feature/appointments, release/1.0.0 и hotfix/1.0.1.
Скрипт docs/gitflow/run_demo.py создаёт новый локальный репозиторий при первом запуске. Не запускать поверх существующего примера. Команды и результаты сохранены в docs/gitflow/transcripts/.

В удалённом репозитории клиники выполнены PR #2 feature → develop, #4 release → main, #3 release → develop, #5 hotfix → main, #6 hotfix → develop. Релизы v1.0.0 и v1.0.1 опубликованы. Локальный пример и удалённый проект имеют собственные истории коммитов.
