# GitHub Desktop на Mac

Открыть GitHub Desktop и выполнить File → Clone Repository → URL.
Адрес: https://github.com/SoftyMaNA/zdorovye-plus-clinic.git
Выбрать локальную папку без пробелов и нажать Clone.

1. Current branch → develop. Repository → Open in Visual Studio Code.
2. Добавить файл docs/desktop-note.md с коротким описанием проекта.
3. Вернуться в Changes, выбрать файл и проверить diff.
4. Summary: docs: add desktop note. Commit to develop.
5. Push origin. При запросе входа авторизоваться в своём GitHub.
6. Открыть History и выбрать созданный коммит.
7. Fetch origin получает сведения; Pull origin применяет новые изменения.

Для отчёта нужны три реальных скриншота: Clone Repository с адресом; Changes с изменением и Summary; History после Push origin. Имя пользователя на GitHub соответствует аккаунту, локальное имя автора задаётся в Settings → Git.

Это инструкция выполнения в приложении. Она не является протоколом уже выполненных действий GitHub Desktop.
